# Formulaire — mémo de formules pour Casio Graph 90+E

Application gint (fxSDK) qui affiche un formulaire de mathématiques classé par
thèmes, avec un **moteur de formules maison inspiré de TeX** : vraies
intégrales et sommes à la taille « hors-texte », bornes placées comme dans un
manuel, fractions, racines, parenthèses et accolades qui s'étirent, matrices,
vecteurs fléchés, alignement sur le signe =.

## Compiler et installer

```sh
cd FORMULAIRE_GRAPH90E
fxsdk build-cg
```

Copier `Formulaire.g3a` à la racine de la mémoire de stockage de la
calculatrice (câble USB, mode « Clé USB »). L'application ne dépend que de
gint (pas de CASIO_GUI, pas de fichiers à installer à côté).

## Ajouter ou modifier des formules

Chaque thème est un fichier `src/content/ch_*.cpp` qui contient un texte,
une directive par ligne. Une directive continue jusqu'à la ligne suivante qui
commence par `@` (on peut donc couper une longue ligne).

```
@page Titre de la page              nouvelle page (entrée du sommaire)
@card Titre de la carte             nouvelle carte (bloc sélectionnable)
@tags mots clés                     pour la recherche (sans accents de préférence)
@math \int_a^b f(t)\,dt             formule centrée (style hors-texte)
@align (uv)' &= u'v+uv'             lignes alignées sur & (lignes @align consécutives)
@align &\quad + ...                 suite d'une formule coupée
@table[ccl] f(x) & f'(x) & \text{Domaine}    en-tête d'un tableau (cellules en LaTeX)
@row x^n & n\,x^{n-1} & \mathbb{R}           ligne du tableau (format l/c/r facultatif)
@text Texte avec $x^2$ et **gras**.          paragraphe
@note Remarque en petit.                      remarque grise
@li Élément de liste.                         puce
@sub Sous-titre                               sous-titre dans une carte
% commentaire
```

Nouveau thème : créer `src/content/ch_xxx.cpp` sur le modèle des autres et
l'ajouter dans `src/content/Chapters.cpp` (titre, libellé, icône en LaTeX,
couleur). L'accueil est une grille de 4 colonnes qui défile verticalement (4 rangées visibles, 32 thèmes au maximum).

**Largeur** : une ligne de formule ne doit pas dépasser la largeur de l'écran
(369 px dans une carte). Une formule `@math` trop large est coupée
automatiquement à ses `\qquad` ; sinon le test ci-dessous la signale et il
suffit de la couper (`@align` ou deux `@math`).

### LaTeX reconnu

- Structure : `^ _ ' {}` `\frac \dfrac \tfrac \binom \sqrt \sqrt[n]` `\left( … \right)`
  (aussi `[ ] \{ \} | \| \langle \rangle \lfloor \rfloor . `), `\big \Big \bigg \Bigg`.
- Grands opérateurs : `\int \iint \iiint \oint \oiint \sum \prod \bigcup \bigcap`,
  `\lim \max \min \sup \inf` (bornes dessus/dessous), `\limits \nolimits`.
- Fonctions : `\sin \cos \tan \cotan \arcsin \arccos \arctan \sh \ch \th \argsh
  \argch \argth \sinh \cosh \tanh \ln \log \exp \det \tr \rg \Ker \dim \Re \Im
  \grad \rot \divg \com \operatorname{…}`.
- Accents : `\vec \overrightarrow \hat \widehat \bar \overline \underline \dot
  \ddot \tilde \check`.
- Environnements : `matrix pmatrix bmatrix vmatrix Vmatrix Bmatrix cases array{lcr}`
  (`array{cc|c}` trace un trait vertical : matrices augmentées).
- Polices : `\mathrm \mathbf \mathbb \mathcal \mathit \text`.
- Divers : `\overset \underset \stackrel \xrightarrow[dessous]{dessus}
  \xleftarrow \boxed \phantom \color{red}{…}` (red, blue, green, orange,
  purple, teal, gray), espaces `\, \: \; \! \quad \qquad ~`, styles
  `\displaystyle \textstyle`.
- Symboles : lettres grecques, `\infty \partial \nabla \forall \exists \in
  \notin \subset \cup \cap \wedge \times \cdot \pm \leq \geq \neq \approx \equiv
  \sim \to \mapsto \Rightarrow \iff \implies \perp \parallel \cdots \ldots`… et
  tout caractère Unicode présent dans la police (ex. `ℝ`, `≤`).
- Les intervalles à la française `]a,b[` sont espacés correctement.

## Organisation du code

```
src/main.cpp            boucle principale (MENU géré comme CASIO_GAME / EM_FIELD)
src/gfx/                Canvas (VRAM, transparence 4 bits), DisplayList, couleurs
src/font/               accès aux polices générées (recherche de glyphes, texte)
src/gen/                polices générées (ne pas modifier à la main)
src/math/               moteur de formules : Parser (LaTeX), Layout (boîtes TeX), Symbols
src/doc/                Index (pages, cartes, recherche), PageLayout (cartes, tableaux, textes)
src/ui/                 App (accueil, page, zoom, sommaire, recherche), KeyMap
src/content/            fiches (une par thème) et liste des thèmes
tools/fontgen/          génération des polices et des icônes (Python)
tools/host_sim/         simulateur PC (faux en-têtes gint, clavier scripté, captures)
tools/tests/            vérification du contenu, vérification numérique des formules
```

### Le moteur de formules

- Mise en page d'après l'annexe G du TeXbook et les constantes de la table
  **MATH OpenType** de la police *DejaVu Math TeX Gyre* (positions des
  exposants et indices, fractions, bornes, radicaux, axe mathématique…), avec
  les styles D/T/S/SS et l'espacement automatique entre atomes (Ord, Op, Bin,
  Rel…).
- **Grands opérateurs** : en style hors-texte, la variante de taille de la
  police (∫ plus grand, ∑ à bornes dessus/dessous) ; bornes de l'intégrale à
  droite, décalées selon la correction d'italique.
- **Délimiteurs et radicaux** : variantes de taille, puis assemblage
  (haut + extension + milieu + bas) pour toute hauteur ; les morceaux sont
  rendus de façon à se raccorder sans couture.
- Les grands symboles sont légèrement épaissis pour bien ressortir sur l'écran.
- Tous les glyphes sont pré-rendus en niveaux de gris (16 niveaux) puis
  mélangés à l'écran : rendu identique sur le simulateur et sur la
  calculatrice (aucune dépendance aux polices de gint).
- Les styles d'indice utilisent les variantes « ssty » de la police (glyphes
  dessinés pour les petites tailles, plus lisibles).
- Mémoire : zones statiques (aucune allocation dynamique), calcul entier
  uniquement (pas de flottants), pas de `snprintf`, pas de bibliothèque C++.

## Tests (sur PC, WSL)

```sh
tools/tests/run_tests.sh              # toutes les pages et cartes : erreurs LaTeX,
                                      # lignes trop larges, glyphes absents, capacités
tools/tests/run_tests.sh -png DIR     # + une image PPM de chaque page dans DIR
python3 tools/tests/verify_formulas.py   # vérification numérique (numpy)
tools/host_sim/build.sh               # simulateur (ASan/UBSan)
tools/host_sim/formulaire_sim script.txt
```

Script du simulateur : `key EXE`, `key DOWN 3`, `type ipp`, `shot fichier.ppm`,
`fuzz 50000 7`. Le fuzz de 80 000 touches passe sans erreur ASan/UBSan.

## Régénérer les polices (facultatif)

Les fichiers `src/gen/*` sont fournis. Pour changer les tailles ou ajouter des
caractères (`TEXT_CPS`, `MATH_CPS` dans `tools/fontgen/gen_fonts.py`) :

```sh
sudo apt install fonts-dejavu fonts-dejavu-extra python3-pil python3-numpy python3-fonttools
python3 tools/fontgen/gen_fonts.py
python3 tools/fontgen/gen_icons.py
```

(Si les polices ne sont pas dans `/usr/share/fonts/truetype/dejavu`, les
copier dans `tools/fontgen/fonts/`.)

## Points à vérifier sur la calculatrice

- Le programme écrit directement dans `gint_vram` (le pointeur de VRAM que
  gint déclare dans `<gint/display-cg.h>`, inclus par `<gint/display.h>`).
  C'est le seul accès bas niveau : il est utilisé une fois, dans
  `src/main.cpp`.
- Répétition des flèches : `getkey_opt(GETKEY_REP_ARROWS, NULL)`.
- Taille : environ 600 Ko de polices dans le .g3a ; environ 140 Ko de RAM
  statique.
